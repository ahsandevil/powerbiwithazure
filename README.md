# End-to-End Azure Data Engineering & Power BI Analytics Pipeline

## Project Overview

This project demonstrates a complete modern data engineering pipeline built on the Microsoft Azure ecosystem. The solution automates data ingestion, validation, transformation, storage, and business intelligence reporting using Azure cloud services.

## Architecture

**Git Repository**
↓
**Azure Data Factory**
↓
**JSON Parameter Validation & Dynamic Pipeline**
↓
**Azure Databricks**
↓
**Azure Synapse Analytics (SQL Database)**
↓
**Power BI Dashboard**

## Technologies Used

* Microsoft Azure
* Azure Data Factory (ADF)
* Azure Databricks
* Azure Synapse Analytics
* Azure SQL Database
* Power BI
* Git
* JSON
* SQL
* PySpark

## Workflow

### 1. Source Control

* Managed project files and datasets using Git.
* Maintained version control for pipeline development.

### 2. Dynamic Pipeline Configuration

* Used JSON parameter files to validate and pass dynamic parameters.
* Enabled reusable and configurable Azure Data Factory pipelines.

### 3. Data Ingestion

* Created Azure Data Factory pipelines to ingest data from the source.
* Automated data movement with parameterized datasets and linked services.

### 4. Data Transformation

* Processed and transformed raw data using Azure Databricks.
* Applied data cleansing, filtering, and business transformation logic using PySpark.

### 5. Data Warehousing

* Loaded transformed data into Azure Synapse Analytics SQL Database.
* Designed the warehouse for fast analytical queries and reporting.

### 6. Business Intelligence

* Connected Power BI to Azure Synapse.
* Built interactive dashboards to visualize KPIs, trends, and business insights.

## Key Features

* End-to-end Azure data pipeline
* Dynamic parameter passing using JSON
* Automated ETL workflow
* Data transformation with Azure Databricks
* Centralized analytics in Azure Synapse
* Interactive Power BI dashboards
